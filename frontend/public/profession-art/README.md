# Profession art

Blizzard UI art from WoW Forever's Professions window (client build
1.60.1.70245, the `wow_cn_beta` product on wago.tools), cropped from its
texture atlases (`UiTextureAtlasMember`) and saved as WebP:

- `background-overview`, `background-crafting`: Profession-Background-Overview / -Template2
- `card-<profession>`, `card-primary-empty`: Profession-overview-Card[-<Profession>] (c60)
- `card-cooking`, `card-fishing`, `card-first-aid`: Profession-overview-card-generic-*
- `schematic-<profession>`: Profession-background-card-<Profession> (crafting page art)
- `fill-<profession>`, `fill-default`: first frame of Skillbar_Fill_Flipbook_<Profession>
- `bar-background`, `bar-frame`: Profession-ProgressBar-BG / -frame
- `header-*`: Professions-recipe-header-left/middle/right/expand/collapse
- `list-background`: Professions-background-summarylist
- `slot-frame`, `slot-background`: Professions-Slot-Frame / -bg
- `tab-professions`: INV_SideTab_Professions_c60 (FileDataID 8197101)

`../wow-art/question-mark.webp` is INV_Misc_QuestionMark (FileDataID 134400),
the game's icon for anything without one.
